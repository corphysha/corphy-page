## What is vgpu?

[vgpu](https://vgpu.sh/) is a small, composable WebGPU library with tooling designed for coding agents: one `Gpu` context, explicit WGSL bindings, explicit frames — and a CLI (`npx vgpu docs`) that lets an agent read the entire API before writing a line of code.

**The shader at the top of this page is real.** If your browser supports WebGPU, it is rendering right now on your GPU — a Corphish-orange metaball-ish plasma field, powered by ~30 lines of WGSL. Check `navigator.gpu` — this is not a GIF.

## Why a library built *for* agents?

Traditional GPU programming assumes a human with a GUI. vgpu assumes an agent:

- **`npx vgpu docs`** — a CLI that serves the full documentation, symbols and examples as markdown
- **Headless rendering** — `vgpu/node` runs through Dawn, so an agent can render and *read pixels back* without a browser
- **`npx vgpu doctor`** — a JSON verdict on whether the runtime can render at all, with exact fixes
- **MCP server** — agents can plug directly into docs + verified examples

## The whole shader program

Here is the *entire* rendering code driving the canvas above — no framework, no boilerplate:

```typescript
import { clock, init, effect, frameLoop, surface } from "vgpu";

const gpu = await init();
const canvasSurface = surface(gpu, canvas, { dpr: [1, 2] });
const plasma = effect(gpu, WGSL, {
  set: { params: { time: 0, texel: canvasSurface.texelSize } },
});

const time = clock(gpu);
frameLoop(gpu, (frame) => {
  plasma.set({ params: { time: time.time } });
  frame.pass(canvasSurface, plasma);
});
```

And the fragment shader itself:

```wgsl
struct Params { time: f32, texel: vec2f }
@group(0) @binding(0) var<uniform> params: Params;

@fragment fn fs_main(@location(0) uv: vec2f) -> @location(0) vec4f {
  let p = uv * vec2f(3.0, 2.0);
  let t = params.time;
  var d = 0.0;
  for (var i = 0; i < 5; i++) {
    let fi = f32(i);
    let center = vec2f(
      0.5 + 0.4 * sin(t * (0.7 + fi * 0.13) + fi * 2.1),
      0.5 + 0.4 * cos(t * (0.9 + fi * 0.11) + fi * 1.7)
    );
    d += 0.16 / (distance(p, center * vec2f(3.0, 2.0)) + 0.05);
  }
  let glow = smoothstep(1.2, 2.8, d);
  let deep = vec3f(0.043, 0.102, 0.180);   // deep ocean
  let crab = vec3f(0.949, 0.388, 0.165);   // corphish orange
  return vec4f(mix(deep, crab, glow), 1.0);
}
```

## Two habits from the docs

1. **Bindings are set by WGSL name** — `params` is a struct, so members nest inside it.
2. **`set()` writes immediately** — so the render loop only writes what actually changes (`time`). Size-class values like `texel` belong in the resize handler.
